# 這誰？選哪？— 2026 縣市長候選人臉與地圖配對挑戰

手機版網頁小遊戲：60 秒內看照片認出 2026 縣市長候選人，再從 4 個縣市輪廓中選出他參選的縣市。每 5 連擊加 3 秒，結束後有結算頁與分享。

## 照片與中立性

- 照片只用 Wikimedia Commons，或政府機關依其資料開放宣告提供的官方肖像，且限 **公眾領域、CC0、CC BY、CC BY-SA、政府資料開放授權條款**。不用新聞照、競選官網照、臉書照、中選會選舉公報照（著作權歸屬不明確）。每張都經人工審核，作者與授權逐張列在遊戲內的「照片授權與資料來源」頁。
- 不顯示政黨顏色、不排序、不評論；作答後才揭曉姓名、政黨、縣市。所有候選人一律同樣處理，不醜化、不配字、不加工。
- 沒有開放授權照片的參選人未收錄（多為小黨與無黨籍），題庫因此偏向主要政黨。
- 名單為 2026/9/4 登記截止的**登記**參選人，可能與 11/17 中選會公告的正式候選人名單有出入（例如有人退選或資格不符）。

## 開發

純靜態網站，不需要 build，整個資料夾直接部署即可。

```sh
python3 -m http.server 8000   # 本機預覽 http://localhost:8000
```

題庫與縣市輪廓由 `scripts/` 產生，依序是 `build_maps.mjs` → `find_photos.py` → 人工審核 `data/photo-review.json` → `build_photos.py`。每支腳本開頭寫了自己的輸入、輸出與執行方式（`build_photos.py` 需要 venv 裝 OpenCV）。
